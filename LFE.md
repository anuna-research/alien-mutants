# LFE

Lisp Flavoured Erlang: a Lisp syntax that compiles to the same BEAM bytecode
as Erlang, sharing OTP, the process model, and the standard toolchain. Source
files use `.lfe` and s-expression syntax (`(defun name (args) body)`).
Referenced by [[SPEC-001-lfe-mutation-testing]] as the language
alien-mutants mutates.
